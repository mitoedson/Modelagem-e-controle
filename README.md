# Modelagem e Controle

Estrutura da disciplina

1. Modelagem matemática de sistemas dinâmicos
+ Através de equações diferenciais ($\dot 𝑥 = 𝛼𝑥$)
+ No espaço de estados (representação matricial, múltiplas variáveis de estado)

2. Análise de estabilidade de sistemas dinâmicos

+ Lyapunov (estabilidade, estabilidade assintótica, instabilidade)
+ Estabilidade para sistemas lineares (autovalores, critério de Routh-Hurwitz, etc.)

3. Princípios de controle

+ Malha aberta vs. malha fechada (feedback)
+ Conceitos de por que realimentação é necessária para corrigir desvios do equilíbrio

4. Projeto de controladores elementares no domínio do tempo

+ PID e variantes, resposta transitória, especificações de desempenho (tempo de subida, overshoot, erro em regime permanente, etc.)
